Welcome, tester

PCEStudio is a PC Engine (TurboGrafx-16) studio that runs in your browser. You write small programs, called toys, in Lua. They run on a model of the console's real graphics and sound chips, and simple toys can be exported as a .pce ROM. Thank you for trying it this early. Every bug you report makes it better.

This is a beta. Things will break, and some parts are not finished. The list of what does not work yet is below, so you don't spend time reporting things we already know about. Anything not on that list is worth reporting.

1. Start in two minutes

  1. Open Browse and pick a game, for example TOWER or PLATFORMER. Its page starts playing at once; Play full screen gives you a bigger picture.
  2. Click on the picture so it gets your keyboard, then play. The keys are in the next section.
  3. To look inside, press Open in Studio. The code is on the left and the running console on the right, with the chips' memory in the panels below. In the studio, press ▶ to run. A game keeps running until you press ■ (Stop).

Use a desktop browser. Phones and tablets have not been tested. If a page looks old or half-updated, press Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows/Linux) to reload it fully.

2. Keys

Click the game picture first, then:

KeyboardPC Engine pad
I J K LUp, Left, Down, Right
NButton I (fire or jump in most games)
MButton II
O / PSelect / Run

Careful: the keyboard key I is Up, while pad button I is the key N. When you report a bug, please write the keyboard key you pressed.

3. Make a game with an AI

With a chat AI (Claude, ChatGPT, …)

  1. In the studio, press Download for Claude, or get the guide here: pcestudio-for-claude.md.
  2. Start a new chat, attach the file, and say what you want, for example "make me a small PC Engine game where a cat jumps over boxes".
  3. Copy the Lua the AI writes and press Paste & Run in the studio. Or save it as a .lua file and drag it onto the studio.
  4. Tell the AI what you see, including any error. The guide teaches it to fix its own code.

The guide makes the AI draw sprites and tiles in code. To use a picture of your own, use ASSETS → Add Source in the studio. Drop a PNG there, and tell the AI which pattern number it got.

With Claude Code (it drives the studio itself)

PCEStudio has an MCP server, so Claude Code can write a toy, run it, look at the frames, add art from a PNG and check it, without you copying anything. You need Node.js. The full manual, with installation for macOS, Linux and Windows, examples and troubleshooting, is here: PCEStudio with Claude Code. The short version (macOS/Linux):

git clone https://github.com/terracide303/PCEStudio-public.git
cd PCEStudio-public
claude mcp add pcestudio -- node "$PWD/tools/mcp/server.js"
mkdir -p ~/.claude/skills
ln -s "$PWD/plugin/skills/creating-pce-toys" ~/.claude/skills/creating-pce-toys

4. A tour of the studio

WhereWhat it does
Run · ▶ ■ −1 +1Run the toy, stop it, step one frame. The scrubber lets you go back in time. Length is how many frames the scrubber keeps; it does not stop a game.
Paste & RunTakes Lua from the clipboard into main.lua and runs it.
CheckThe validator: does the toy fit the console's limits (sprites per line, VRAM, frame time)?
Export…Builds a .pce ROM in the browser. Only simple toys for now (see section 6).
Save file / Open…Saves the whole toy (code and assets) as one .pce.json file, and opens one again. Use this to send us a toy that shows a bug.
CODE · ASSETSThe toy's Lua files, and its art, palettes, waves, songs and the 15 built-in instruments.
Panels: SCREEN, VRAM, PALETTES, SPRITES, AUDIO, SEQUENCER, LAYERS, SCANLINES, REGISTERS, CONSOLEThe console's insides while it runs. CONSOLE shows the toy's print() output and its errors. Please copy them into a bug report.
DocsThe full toy API, generated from the code.

5. What we'd love you to test

  • Play every game in Browse for a minute or two. Look for anything that freezes, flickers, sounds wrong, or ignores a key.
  • Make one toy with an AI using the guide. Did the AI's first try run? What error did you get? Where did you get stuck? This is the most useful report of all.
  • Change something in a game's code and press Run. Does the studio tell you clearly what's wrong when you break it?
  • Export a simple toy (try Sky gradient) and run the .pce in an emulator (Mednafen, Ares, …) or on real hardware. If you own a real PC Engine with a flash cart, we'd especially like to hear from you: nothing has run on real hardware yet.
  • Your browser and computer. Tell us what you use, even if everything works.

7. How to report a bug

Bugs go to GitHub Issues: github.com/terracide303/PCEStudio-public/issues. You need a free GitHub account. Choose Bug report; the form asks for everything below.

  1. Search first. If someone already reported it, add a comment or a 👍 instead of a new issue.
  2. One problem per issue. Two bugs in one issue tend to get half-fixed.
  3. A clear title that says what goes wrong, for example "TOWER: the player falls through the second ladder", not "broken".
  4. Steps: what you did, click by click, starting from opening the page.
  5. What you expected and what happened instead.
  6. The frame number shown under the picture (for example frame 2089) and any red text from the CONSOLE panel or the Export/Check window. Copy the text; a screenshot of text is hard to search.
  7. The toy: press Save file and attach the .pce.json (zip it if GitHub refuses the file), or paste the Lua inside a code block. If it's one of the games in Browse, its name is enough.
  8. Your browser and system, for example Chrome 141 on macOS 26.
  9. A screenshot or a short screen recording when it's something you see or hear.

Please don't put passwords, API keys or private information in an issue: issues are public.

What happens next

We read every issue and turn the real ones into work on our board. The issue gets a label (bug, confirmed, fixed on the site) and a comment when the fix is live. If we can't reproduce it, we'll ask you a question in the issue, so watch for replies.

8. Ideas and your own toys

  • Ideas and "it would be great if…" go in an issue too: choose Idea.
  • Made something you like? Choose Share a toy and attach the .pce.json. With your OK, good ones go into Browse with your name on them.
  • Only share art you made yourself or are allowed to share (check the licence of any art pack you use).
